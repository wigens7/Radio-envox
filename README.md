# Radio Lakay

Dashboard Radio Lakay la ak yon sèvè Node.js + Express.

## Kòmanse lokalman

1. Enstale Node.js 18 oswa pi resan.
2. Nan folder pwojè a, kouri `npm install`.
3. Kouri `npm start`.
4. Louvri `http://localhost:3000`.

## Deplwaman

Sou Railway, mete kòmand build la vid oswa `npm install`, epi kòmand start la `npm start`.
Railway ap bay pò a atravè varyab anviwònman `PORT`.

Nòt: Player la ak chat la nan HTML aktyèl la se entèfas demonstrasyon. Pou difize odyo an dirèk ak chat ki mache ant plizyè vizitè, fòk nou ajoute yon sous stream odyo ak yon backend realtime.
